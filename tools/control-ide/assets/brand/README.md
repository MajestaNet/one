# Majesta.Net brand artwork (Control IDE)

Vendored subset of the August 2026 identity from [`MajestaNet/webpage`](https://github.com/MajestaNet/webpage) `public/brand/`.

**Source commit:** `126f458297875a164c109ac2db12bc4dfda1baf7`

Use the SVG files. Do **not** type the `MAJESTA.NET` wordmark. The globe is the compact mark; the full lockup stays at least 180px wide.

| File | Use in Control IDE |
|---|---|
| `symbol-gold.svg` / `symbol-navy.svg` | Top-bar globe (theme-picked) |
| `logo-gold.svg` | Sign in / mode launcher on dark |
| `logo-two-colour.svg` | Sign in / mode launcher on light |
| `logo-white.svg` / `logo-navy.svg` / `logo.svg` / `symbol.svg` / `symbol-white.svg` | Spare lockups / `currentColor` |
| `symbol/gold-{256,512,1024}.png` | Raster source for the app icon |
| `app-icon.png` | Gold globe on navy, 1024² — electron-builder **and** running window/dock (`BrowserWindow` / `app.dock`) |
| `app-icon.svg` | Composed source for the raster app icon |

Ivory lockups, site CSS, and marketing fonts are **not** copied.
